# 拾读 Glean 素材

来源与授权的完整说明见 [content/SOURCES.md](../content/SOURCES.md)；封面逐张署名见 [content/COVER_CREDITS.md](../content/COVER_CREDITS.md)。

| 目录 | 内容 |
|---|---|
| `brand/app-icon.png` | 应用图标原图（Android 自适应图标与 iOS 图标由它导出） |
| `brand/splash.webp` | 开屏插画（米白底 + 墨绿），原生开屏同色 `@color/splash_cream` |
| `covers/*.webp` | 每篇文章一张封面，来自 Wikimedia Commons；`manifest.json` 记录尺寸、主色、作者与许可。没有封面的文章由 `ArticleCover` 程序绘制书封 |
| `illustrations/*.svg` | 状态插画：暂无文章、单词本为空、离线、读完 |
| `illustrations/reading.webp` | 欢迎 / 阅读引导插画 |
| `seed/` | 种子数据：文章、远端文章池、词典子集、AI 导读与阅读理解题、版本清单 |
